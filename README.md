# Finance Tracker

A Python-based Finance Tracker that analyzes bank transactions and generates categorized reports and spending charts.

## Features

- Categorizes transactions automatically
- Generates yearly financial reports
- Creates monthly spending charts
- Exports categorized transactions to Excel
- Visualizes expenses with graphs

## Technologies Used

- Python
- Pandas
- Matplotlib
- OpenPyXL

## How to Run

1. Install required libraries:

```bash
pip install pandas matplotlib openpyxl
```

2. Run:

```bash
python main.py
```
